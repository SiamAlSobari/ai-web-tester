# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

## Reporting a Vulnerability

We take the security of `ai-web-tester` seriously. If you believe you have found a security vulnerability in this project, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories at:
   https://github.com/SiamAlSobari/ai-web-tester/security/advisories/new
   or contact the maintainer directly via email: `siamqueen52@gmail.com`.
3. Provide a clear description of the vulnerability, reproduction steps, and any proof-of-concept code.

We will acknowledge receipt within 48 hours and work with you on a coordinated fix and release.
