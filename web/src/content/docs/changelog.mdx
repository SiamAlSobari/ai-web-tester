## 0.3.2 — NPX Universal Binary & Seamless Uninstaller Suite

- **NPX Universal Binary**: Added `"ai-web-tester"` binary mapping to `package.json` for zero-install `npx ai-web-tester init` and `npx ai-web-tester uninstall` workflows.
- **Robust Path Resolution**: Replaced static `process.cwd()` project roots with dynamic `import.meta.url` resolution for global and npx-based MCP registration.
- **Comprehensive Clean Uninstaller**: Standardized 4-mode uninstallation guide covering End-Users (`npx`), Global NPM (`npm i -g`), Local Developers (`npm unlink`), and manual configurations.
- **Documentation**: Updated `INSTALL.md` with explicit non-developer uninstall instructions and agent-specific configuration paths.

## 0.3.1 — Full-Spectrum Self-Healing & Smart Fuzzing Suite

- **19 MCP Tools**: Added `browser_fill_form` (Smart Form Auto-Filler & Security Fuzzing) and `browser_generate_scenario`.
- **Self-Healing Locator V2**: Full-spectrum selector recovery (`[data-testid]`, `[data-test]`, `[data-cy]`, `#id`, `[name]`, role text matching) across click, fill, select, hover, and upload.
- **Element Context V2**: Real-time `[in-viewport]` vs `[below-fold]` positional badges, `<select>` option lists, and smart SVG icon labeling.
- **Security & Telemetry V2**: `SECURITY_WARNING` tagging for CORS and CSP violations, `SLOW_NETWORK_WARNING` for >2000ms latency endpoints, and formatted JSON response bodies.
- **Autonomous Crawler V2**: Deep form structure inspection (`action`, `method`, `inputs`) and authenticated crawling via `storageState`.
- **Scenario Runner V2**: Per-row `beforeEach`/`afterEach` hooks, `${{ env.VAR }}` interpolation, and `fill_form` step support.
- **Developer Tools**: `ai-test doctor` environment probe, `ai-test repl` interactive QA shell, `ai-test generate` auto-scenario generator, `--replay-har` offline fixtures, and `--github-summary` CI step summary.
- **Dashboard UX**: Real-time search filter and status filtering (`All`, `Passed`, `Failed`) with live SSE feed.
