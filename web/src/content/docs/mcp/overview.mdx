---
title: MCP Overview
description: 24 Model Context Protocol tools over stdio.
---

Transport is handled over `stdio` via `dist/mcp.js`. Security controls include `allowedHosts` SSRF guard and origin filtering.

| Tool | Parameters | Description |
| :--- | :--- | :--- |
| `browser_open` | `url`, `headless`, `device`, `browser`, `storageState`, `replayHar`, `networkProfile`, `recordTrace` | Launch browser session and extract initial ARIA tree |
| `browser_act` | `action`, `ref`, `value`, `filePaths`, `screenshotName` | Interaction execution with hierarchical self-healing |
| `browser_fill_form` | `formRef`, `mode` ('valid'/'fuzz'), `overrides` | Smart form auto-fill and security fuzzing engine |
| `browser_generate_scenario` | `name` | Auto-generates replayable YAML test scenario |
| `browser_inspect` | `sessionId` | Refresh interactive refs, scroll info, and recent issues |
| `browser_console_logs` | `limit`, `type` ('all'/'error'/'warning'/'info'/'log') | Query recent browser console logs on demand |
| `browser_network_logs` | `limit`, `failedOnly` | Query recent HTTP requests, status codes, and latencies |
| `browser_switch_tab` | `tabIndex` | Multi-tab and OAuth popup window switching |
| `browser_save_auth` | `path` | Persist authentication storageState (cookies and localStorage) |
| `browser_audit_a11y` | `sessionId` | axe-core automated WCAG 2.1 AA compliance audit |
| `browser_crawl` | `url`, `maxDepth`, `maxPages` | Deep crawling, broken link verification, and form discovery |
| `browser_screenshot` | `name`, `fullPage`, `compareBaseline`, `threshold` | Capture screenshot with pixelmatch visual regression |
| `browser_live_screenshot` | `fullPage` | Live base64 screenshot capture for real-time dashboards |
| `browser_report` | `title`, `outputPath` | Markdown test report generation with YAML frontmatter |
| `browser_report_junit` | `outputPath` | Export JUnit XML report for CI/CD pipeline ingestors |
| `browser_report_html` | `outputPath` | Export self-contained styled HTML test report |
| `browser_run_scenario` | `path` | Replay YAML scenario with data-driven concurrency |
| `browser_sessions` | `none` | List all active browser contexts and session IDs |
| `browser_assert` | `kind`, `ref`, `expected`, `operator`, `timeoutMs` | Page state assertions (visible, text, value, checked) |
| `browser_assert_perf` | `metric`, `thresholdMs`, `operator` | Web Vitals performance budget enforcement |
| `browser_mock` | `urlPattern`, `status`, `body`, `contentType` | Network route mocking for 4xx/5xx simulations |
| `browser_mock_reset` | `urlPattern` | Clear all mocked routes or specific URL pattern |
| `browser_health` | `none` | Health probe reporting browser version, status, and memory |
| `browser_wait_for` | `ref`, `state`, `timeoutMs` | Deterministic wait for element attachment or visibility |
| `browser_extract` | `ref`, `attribute` | Extract text, value, HTML, or href attribute for chaining |
| `browser_close` | `sessionId` | Session teardown and browser resource reclamation |
