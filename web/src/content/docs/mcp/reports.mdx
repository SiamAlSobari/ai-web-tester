`browser_report` compiles `TestReport` (status PASSED/FAILED/WARNING) with frontmatter, exec table, perf breakdown, issue cards, screenshot links, recommendations. Outputs under `test-reports/`.

`browser_report_junit` → `junit-*.xml` for CI annotations. `browser_report_html` → dark HTML.
