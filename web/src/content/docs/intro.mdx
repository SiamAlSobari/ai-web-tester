**AI Web Tester** is a headless Chromium engine + MCP toolset that lets AI agents (OpenCode, Antigravity, Claude Code, Cursor, Windsurf) actually *use* your web app — not just read its code.

## The blind spot

Agents can refactor components and fix syntax, but they can't experience:

- submit button that doesn't fire in a certain state
- unhandled JS exception that kills React hydration
- validation that accepts `invalid-email`
- modals/infinite scroll that break navigation

We bridge it: open localhost/live URLs, drive multi-step scenarios, catch runtime errors, screenshot anomalies, and compile a Markdown report.

## What you get

- **Senior QA matrices** — empty/required, format/boundary, wrong credentials, injection, happy path
- **Token pruning >90%** — ARIA tree with `[ref=N]` instead of raw HTML
- **Headless by default** — quiet, low RAM, anti-zombie guards
- **Error-only screenshots** → `./artifacts/`
- **360° telemetry** — console.error/warn, pageerror, 4xx/5xx
- **Reports** — Markdown + YAML frontmatter, HTML, JUnit
